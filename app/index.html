      Sources & method

      Official list. Every name, description and grade is shown exactly as PlayStation publishes it, verified against two public trackers read on 2026-11-20: Exophase (exophase.com/game/grand-theft-auto-vi-psn/trophies) and PSNProfiles (psnprofiles.com/trophies/43531-grand-theft-auto-vi). The two agree on every name, description and grade, and on the make-up: 55 trophies, 1 platinum, 2 gold, 6 silver, 46 bronze. Where PSNProfiles shows a PSN progress target (for example 0/42 Shooting Range challenges), it is shown beside the trophy.

      Guides. Every guide is original writing for this entry, built only from the official descriptions plus the PSN targets. No walkthrough location or step is claimed beyond what those sources pin down. Where the official description does not pin down a trigger — the cryptic ones, such as “What the hell just happened?” — the guide says so plainly instead of inventing a step.

      Roadmap and missables. Both are built from the official descriptions: the roadmap orders the trophies by what the descriptions ask for (story chapters and missions, stranger strands, collectibles and counts, then the activity grind and 100%), and a trophy is flagged missable only where its description names one specific mission, place or choice.

      Your progress. Checkboxes save in this browser only (localStorage). Export downloads a JSON file; import reads one back. Nothing is uploaded anywhere, and the app makes no network request at all — it works with the network off. No Rockstar logo, artwork or game screenshot is used anywhere in this guide.
